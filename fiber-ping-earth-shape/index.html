Can a ping outrun light on a flat map?

A round trip over fiber can't be faster than light covering the distance twice. Network detours, queues and routers only add time. So the fastest ping between two cities caps how far apart they can be, and any map that puts them farther apart is wrong.

Each pair is plotted twice at the same height: a filled dot at its globe distance and a hollow ring at its flat-map distance. A point inside the shaded wedge would need a signal faster than light. On the globe nothing lands there. On the flat map, Auckland → Sydney and Perth → Sydney do.

2 · The same three cities on two maps
flat: d² = r₁² + r₂² − 2r₁r₂ cos Δλ,  r = (90° − φ) × 111.195 km    globe: d = 2R asin √(sin²(Δφ/2) + cos φ₁ cos φ₂ sin²(Δλ/2))

The flat map keeps latitude rings evenly spaced from the North Pole, so southern rings are stretched sideways. Auckland–Sydney becomes 5,698 km instead of 2,156 km; Perth–Sydney becomes 8,302 km instead of 3,291 km. From a northern source like Vancouver the stretch is only 0–14%, which is why the first run couldn't separate the models.

6 · Methods and errors
  1. Probes. Globalping, a network of community-hosted probes. One probe per source city; ping and traceroute use the same probe. Run 2 records each probe's reported coordinates; run 1 used the Vancouver city centre.
  2. Targets. Vultr per-datacentre test hosts (one physical site each). Every traceroute was checked to end at the labelled host.
  3. Ping. 16 ICMP echoes per pair; the minimum is used, because every source of delay is one-sided.
  4. Distances. Globe: haversine on a 6,371 km sphere. Flat: north-pole azimuthal equidistant, latitude rings 111.195 km per degree.
  5. Floors. Vacuum 2d/c with c = 299,792.458 km/s (exact). Fiber 2d·ng/c with ng = 1.468.

7 · Limits and next steps (WIP)
  • One map, not all flat maps. This rejects the north-pole azimuthal equidistant layout. The general test collects many pairs' maximum distances (min ping × c ÷ 2) and asks whether any planar arrangement of the cities satisfies them all at once.
  • One run, one probe each. Repeat Perth → Sydney from other networks and times of day; its margin is 3.6σ.
  • Direct South Atlantic route. Cape Town → São Paulo came within 1.03× of the flat fiber floor but did not use the direct cables. Probes on networks that use SACS or SAIL could decide it.
  • Probe coordinates. Run 1 did not log them; the Vancouver script should be updated to match run 2.
