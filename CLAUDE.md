# Simulations repo

Follow "Adding a simulation" in README.md for every new or updated simulation.

- `main` is the publishing branch (GitHub Pages). Branch from `origin/main`
  and open every pull request against `main`, never against another branch.
- Keep each simulation self-contained in its own folder, styled like
  `triangulation-chain/`, with a folder README.
- Update the root `index.html` card list and the README table in the same
  pull request.
- Render the page headless and check the console before opening the PR.
